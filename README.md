# .NET Core Azure Interview Wiki

This repository contains a Markdown-based interview preparation wiki for a **.NET Developer** role focused on backend development, ASP.NET Core, REST APIs, clean architecture, CQRS, Domain-Driven Design, Azure, DevOps, Docker, Kubernetes, testing, and code quality.

The main wiki entry point is:

- [dotnet-interview-wiki/index.md](dotnet-interview-wiki/index.md)

## Who This Is For

- .NET developers with around 3+ years of experience.
- Backend developers preparing for technical interviews in English.
- Candidates who need practical answers for architecture, API design, Azure, DevOps, and testing questions.
- Developers who want realistic business examples instead of toy examples.

## How to Use This Wiki

1. Read the concept overview for each topic.
2. Practice answering the interview questions out loud.
3. Review the sample answers and adapt them to your own project experience.
4. Study the code examples and be ready to explain design choices.
5. Use the real-world scenarios to practice system design and trade-off discussions.

## Format

Each concept page includes:

- Concept overview
- Why the topic matters in a .NET interview
- Practical notes
- Interview questions by difficulty
- Strong sample answers
- Coding example when relevant
- Real-world scenario
- Common mistakes
- Follow-up questions
- Senior-level trade-off discussion
- Summary checklist
